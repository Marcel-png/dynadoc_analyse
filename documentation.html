1. Présentation du projet

DynaRecrut est une application web de gestion de CV qui permet aux recruteurs de :

  • Créer des offres d'emploi avec des critères d'analyse personnalisés (groupes de mots-clés avec poids)
  • Générer un lien de candidature unique pour chaque offre
  • Recevoir les CV des candidats via drag-and-drop (PDF/TXT)
  • Analyser automatiquement les CV : score de compatibilité par groupe de critères et score global pondéré
  • Visualiser les candidatures triées par score, filtrer par seuil minimum
  • Télécharger les CV originaux des candidats
  • Définir une date limite de candidature (lien désactivé après expiration)

Stack technique :

  • Frontend : SvelteKit 5 (mode runes) + TypeScript
  • Styling : UnoCSS + Tailwind (via presetUno)
  • PDF : pdfjs-dist pour l'extraction de texte
  • Persistance : localStorage (aucun backend requis)
  • Build : Vite 8

export interface JobPost {

export interface MatchResult {
  groupId: string;          // ID du groupe
  groupName: string;        // Nom du groupe
  foundKeywords: string[];   // Mots-clés trouvés dans le CV
  missingKeywords: string[]; // Mots-clés absents

  matchPercentage: number;   // Pourcentage de correspondance
}

export interface CandidateApplication {

  jobId: string;             // ID de l'offre associée
  candidateName: string;     // Nom du candidat

}

function generateSlug(title: string): string {
  // Normalise le titre : supprime accents, remplace espaces par -, ajoute 6 caractères aléatoires
  return title.toLowerCase()
    .normalize('NFD').replace(/[\u0300-\u036f]/g, '')
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-|-$/g, '')
    + '-' + Math.random().toString(36).substring(2, 8);
}

Génération du slug

Le slug est généré à partir du titre du poste :

  • Mise en minuscules
  • Suppression des accents (normalisation NFD)
  • Remplacement des caractères non-alphanumériques par des tirets
  • Ajout de 6 caractères aléatoires pour garantir l'unicité

Exemple : "Développeur Full-Stack" → developpeur-full-stack-a3x8k2

5. Extraction PDF (utils/cvParser.ts)

Ce module utilise pdfjs-dist pour extraire le texte des fichiers PDF. Il gère aussi les fichiers TXT.

Initialisation du worker

async function initWorker() {
  const mod = await import('pdfjs-dist');
  pdfjsLib = mod;

  // Stratégie 1 : Worker bundle via Vite (?worker)
  try {
    const worker = await import('pdfjs-dist/build/pdf.worker.mjs?worker');
    pdfjsLib.GlobalWorkerOptions.workerPort = new worker.default();
  } catch {
    // Stratégie 2 : URL locale
    try {
      pdfjsLib.GlobalWorkerOptions.workerSrc = new URL(
        'pdfjs-dist/build/pdf.worker.mjs', import.meta.url
      ).toString();
    } catch {
      // Stratégie 3 : CDN (fallback)
      pdfjsLib.GlobalWorkerOptions.workerSrc =
        `https://cdnjs.cloudflare.com/ajax/libs/pdf.js/${pdfjsLib.version}/pdf.worker.min.mjs`;
    }
  }
}

Extraction du texte

export async function extractTextFromPDF(file: File): Promise<string> {
  await initWorker();
  const arrayBuffer = await file.arrayBuffer();
  const pdf = await pdfjsLib.getDocument({ data: arrayBuffer }).promise;
  let fullText = '';

  for (let i = 1; i <= pdf.numPages; i++) {
    const page = await pdf.getPage(i);
    const content = await page.getTextContent();
    const pageText = content.items
      .map((item: any) => item.str)
      .filter((s: string) => s)
      .join(' ');
    fullText += pageText + '\n';
  }
  return fullText.trim();
}

Fonction d'entrée :

export function extractTextFromFile(file: File): Promise<string> {
  if (file.type === 'application/pdf' || file.name.endsWith('.pdf'))
    return extractTextFromPDF(file);
  return file.text();  // Pour les fichiers .txt
}

6. Calcul de compatibilité (utils/matchCalculator.ts)

Ce module analyse le texte d'un CV par rapport aux critères définis pour une offre.

Fonction calculateMatch

Analyse chaque groupe de critères indépendamment :

export function calculateMatch(cvText: string, criteria: CriterionGroup[]): MatchResult[] {
  const cvLower = cvText.toLowerCase();

  return criteria.map(group => {
    const foundKeywords: string[] = [];
    const missingKeywords: string[] = [];

    for (const keyword of group.keywords) {
      if (cvLower.includes(keyword.text.toLowerCase().trim())) {
        foundKeywords.push(keyword.text);
      } else {
        missingKeywords.push(keyword.text);
      }
    }

    const matchPercentage = group.keywords.length > 0
      ? Math.round((foundKeywords.length / group.keywords.length) * 100)
      : 0;

    return { groupId: group.id, groupName: group.name,
             foundKeywords, missingKeywords,
             totalKeywords: group.keywords.length,
             foundCount: foundKeywords.length, matchPercentage };
  });
}

Fonction calculateOverallMatch (score global pondéré)

Calcule une moyenne pondérée où chaque groupe a un poids :

export function calculateOverallMatch(cvText: string, criteria: CriterionGroup[]): number {
  if (criteria.length === 0) return 0;

  let totalWeight = 0;
  let weightedSum = 0;

  for (const group of criteria) {
    const match = calculateMatch(cvText, [group])[0];
    weightedSum += match.matchPercentage * group.weight;
    totalWeight += group.weight;
  }

  return totalWeight > 0 ? Math.round(weightedSum / totalWeight) : 0;
}

Rôle

Affiche la liste de toutes les offres d'emploi avec des statistiques (nombre de candidatures, score moyen de match). Permet de naviguer vers les détails ou de supprimer une offre.

Structure du code

  • Stats cards : 3 cartes (offres actives, total candidatures, match moyen global) avec icônes colorées
  • Liste des offres : Chaque offre affiche titre, entreprise, date, nombre de groupes de critères, statut deadline, nombre de candidatures et score moyen
  • Modal de suppression : Confirmation avec backdrop blur et boutons gradient

Fonctions clés

function getAppCount(jobId: string): number {
  return getApplications(jobId).length;
}

function getAvgMatch(jobId: string): number {
  const apps = getApplications(jobId);
  if (apps.length === 0) return 0;
  return Math.round(apps.reduce((s, a) => s + a.overallMatch, 0) / apps.length);
}

function handleSubmit() {
  if (!title.trim() || !company.trim()) { error = '...'; return; }
  if (criteria.length === 0) { error = '...'; return; }

  const deadlineTimestamp = deadline ? new Date(deadline).getTime() : null;

  const job = createJob({
    title: title.trim(), company: company.trim(),
    description: description.trim(),
    deadline: deadlineTimestamp,
    criteria,
  });
  goto(`/recruiter/job/${job.id}`);
}

Fonction addGroup

Valide et ajoute le groupe en cours d'édition à la liste des critères, puis réinitialise le formulaire.

function addGroup() {
  if (!groupName.trim()) { error = 'Veuillez donner un nom au groupe'; return; }
  if (keywords.length === 0) { error = 'Ajoutez au moins un mot-clé'; return; }

  const group: CriterionGroup = {
    id: crypto.randomUUID(),
    name: groupName.trim(),
    keywords: [...keywords],
    weight: groupWeight,
  };
  criteria = [...criteria, group];
  // Reset
  groupName = ''; keywords = []; groupWeight = 3; error = '';
}

Gestion du drag-and-drop

function handleDrop(e: DragEvent) {
  e.preventDefault();
  isDragging = false;
  const files = e.dataTransfer?.files;
  if (files && files.length > 0) validateAndSetFile(files[0]);
}

function validateAndSetFile(file: File) {
  // Vérification du type (PDF ou TXT)
  if (!['application/pdf', 'text/plain'].includes(file.type)
      && !file.name.endsWith('.txt') && !file.name.endsWith('.pdf')) {
    error = 'Format non supporté'; return;
  }
  // Limite de taille : 10 Mo
  if (file.size > 10 * 1024 * 1024) {
    error = 'Fichier trop volumineux (max 10 Mo)'; return;
  }
  cvFile = file;
}

Soumission avec analyse

async function handleSubmit() {
  // 1. Lecture du fichier en base64
  const fileBuffer = await cvFile.arrayBuffer();
  const fileBytes = new Uint8Array(fileBuffer);
  let binary = '';
  fileBytes.forEach(byte => binary += String.fromCharCode(byte));
  const cvFileData = btoa(binary);

  // 2. Extraction du texte
  const cvText = await extractTextFromFile(cvFile);

  // 3. Calcul des scores
  const matchResults = calculateMatch(cvText, job.criteria);
  const overallMatch = calculateOverallMatch(cvText, job.criteria);

  // 4. Sauvegarde
  const application: CandidateApplication = {
    id: crypto.randomUUID(), jobId: job.id,
    candidateName: name.trim(), email: email.trim(),
    cvText, cvFileName: cvFile.name,
    cvFileData, cvFileType: cvFile.type,
    matchResults, overallMatch, appliedAt: Date.now(),
  };
  addApplication(application);
  submitted = true;
}

12. Flux utilisateur complet

Parcours recruteur

1. Crée une offre → 2. Définit les critères → 3. Obtient un lien → 4. Partage le lien → 5. Reçoit les CV → 6. Analyse les scores → 7. Télécharge les CV

Parcours candidat

1. Reçoit le lien → 2. Remplit le formulaire → 3. Dépose son CV → 4. Analyse automatique → 5. Confirmation

Cycle de vie d'une candidature

  1. Création de l'offre : Le recruteur remplit le formulaire → createJob() → sauvegarde dans localStorage
  2. Génération du slug : Basé sur le titre + 6 caractères aléatoires → URL unique /apply/[slug]
  3. Dépôt du CV : Le candidat upload son fichier → validation (type, taille) → extraction du texte via pdfjs-dist
  4. Analyse : calculateMatch() cherche chaque mot-clé dans le texte du CV → calculateOverallMatch() calcule la moyenne pondérée
  5. Sauvegarde : addApplication() stocke tout (infos, texte, fichier base64, scores) dans localStorage
  6. Consultation : Le recruteur voit les candidatures triées par score, peut filtrer, voir les détails et télécharger le CV original
